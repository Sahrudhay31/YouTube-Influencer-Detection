# Domain-Aware YouTube Influencer Detection & Promotion-Potential Ranking

A big-data engineering system built on Apache Spark (SQL + MLlib) and columnar Snappy Parquet designed to analyze YouTube creators, evaluate domain authority, detect sponsorship activities, and rank creators by **Promotion-Potential Score** for product marketing campaigns.

> **Storage Runtime Mode:** Runs in **local filesystem mode** (`file:///`) by default for local development without Docker dependencies; a multi-container Apache Hadoop HDFS Docker Compose environment (`docker-compose.yml`) is provided for distributed cluster deployments.

---

## ⚠️ Honest Framing & Scientific Scope

> **Important Disclosure:** Public YouTube metadata contains **zero sales, conversion, or ROI figures**.  
> The system outputs a **Promotion-Potential Score** (a calibrated statistical estimate of promotional fit, audience alignment, and engagement lift), **not measured sales or revenue ROI**. This repository never claims to measure direct sales or guarantee ROI.

## 🏆 Promotion-Potential Scoring & Time-Split Backtest

The composite **Promotion-Potential Score** ranks YouTube channels for marketing sponsorship suitability. It integrates 6 weighted components with dynamic renormalisation conforming to `config/scoring.yaml`:
- **Domain / Product Fit** (25%): TF-IDF cosine similarity between brand/product brief and channel profile.
- **Influencer Probability** (20%): GBT classifier probability from channel behavior signals.
- **Audience Quality & Authenticity** (15%): Low duplicate comments, non-concentrated audience, organic velocity.
- **Promo Lift Track Record** (15%): Historic median view multiplier on sponsored videos vs organic baseline.
- **Size Tier Efficiency** (15%): Engagement rate relative to benchmark CPM rate card (`config/rate_card.yaml`).
- **Consistency & Cadence** (10%): Upload cadence regularity and view consistency (inverse CV).

### Calibration: Spearman Rank Correlation
A `GBTRegressor` was trained on historical channel features to predict promotional lift (`run_20261021_054959_promolift_gbt`). The Spearman rank correlation between model predictions and the composite Promotion-Potential Score is:
- **Spearman $\rho = 0.4585$ ($p = 0.0026$, statistically significant)**.

### Time-Split Backtest Evaluation (Cutoff $T = \text{2019-01-01}$)
Evaluating strictly on unseen post-$T$ videos (6,149 videos, 778 sponsored) across 112 active channels:

| Ranking Method | Precision@5 | Precision@10 | NDCG@5 | NDCG@10 | Spearman $\rho$ | p-value |

*Outcome: The Promotion-Potential Score outperforms both standard baselines on top-5 sponsor conversion Precision and NDCG ranking quality.*

## ⚙️ Configuration

Configuration files are located in `config/`:
- `config/settings.yaml`: Paths, HDFS URIs, random seeds, split ratios (70/15/15), dev sample fractions.
- `config/quota.yaml`: API unit caps (8,000 daily cap, 20 search calls, 1,500 per-run max).
- `config/quota_costs.yaml`: Unit cost per endpoint grounded in official YouTube documentation.
- `config/scoring.yaml`: Calibrated weights for Promotion-Potential Score components.
- `config/domains/taxonomy.yaml`: Hierarchical macro-to-micro domain taxonomy.
- `config/domains/beauty_personal_care.yaml`: Domain keywords, sponsor patterns, and purchase intent phrases.
- `config/enrichment.yaml`: Phase 6 funnel thresholds, comment sampling limits, purchase-intent keyword patterns, loyalty proxy config, and authenticity check thresholds.

## 🛡️ YouTube API Compliance & Privacy Governance

- **Strict Quota Control:** Managed by `src/ingestion/quota_guard.py` with Pacific midnight ledger rollover (`state/quota_ledger.json`).
- **Data Retention Enforcement:** `src/maintenance/purge_api_data.py` enforces deletion of raw API partitions older than 30 days to strictly comply with YouTube Developer Terms.
- **Privacy Hashing:** Commenter channel IDs are irreversibly hashed with `COMMENT_HASH_SALT` for loyalty analysis. Raw usernames and personal identifiers are never stored.

---

## ⚠️ Known Limitations & Assumptions

1. **Historical vs Live Data:** YouNiverse provides a robust historical baseline (2019). Live YouTube API snapshots are used selectively for shortlisted candidates.
2. **Proxy vs Direct Conversion:** Engagement rate, view velocity, and purchase-intent comment ratios serve as proxies for influencer marketing effectiveness, not financial ROI.
3. **Language Scope:** Version 1.0 targets English metadata and comments only.
